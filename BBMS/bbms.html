ABOUT THE PROJECT

Project Overview

About BloodCare

Blood Bank Management System (BBMS), also referred to as BloodCare, is a web-based application designed to manage blood donation and inventory activities.

The system provides features for donor registration, blood stock management, and blood request handling. It helps organize information and makes it easier for administrators to monitor available blood units and manage requests.

Project Details

  • Project BloodCare / BBMS
  • Type Web Application
  • Frontend HTML, CSS, JavaScript
  • Backend Core PHP
  • Database MySQL
  • Environment XAMPP
WHAT IT OFFERS

Key Features

Donor Management

Register donors and maintain their information, including contact details and blood groups.

Blood Inventory

Maintain blood stock records and monitor available blood units by blood group.

Blood Requests

Manage blood requests and organize their approval and processing workflow.

Admin Dashboard

Provide administrators with an overview of donor information, requests, and stock records.

User Authentication

Support controlled access to the system through its authentication functionality.

Responsive Interface

Provide an interface designed to work across desktop and mobile screen sizes.
