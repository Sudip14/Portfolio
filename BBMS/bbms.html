[ PROJECT_OVERVIEW ]

The Blood Bank Management System (BBMS) is a full-stack web application designed to simplify blood donor management, blood inventory tracking, and blood request handling. The system provides a centralized platform for managing donor information and blood availability.

I developed the application using HTML, CSS, JavaScript, Core PHP, and MySQL. The system connects the user interface with backend functionality and database operations to manage donor records, blood stock, and requests.

One of the important aspects of this project was maintaining consistency between blood inventory and request processing. Working on this system helped me improve my understanding of backend development, database design, CRUD operations, and full-stack application development.
